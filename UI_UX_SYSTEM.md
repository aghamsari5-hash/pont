# UI UX SYSTEM — PONT CAFE

Main principle:
Simple, beautiful and fast.

Homepage:
- Logo
- Language selector
- Cafe card
- Restaurant card

Do not add:
- Marketing banners
- Extra text
- Ordering features

Navigation:

Cafe:
Hot Bar
Cold Bar
Dessert

Restaurant:
Breakfast
Lunch
Dinner

Product card:
Only:
- Image
- Name
- Price

Product detail:
- Image
- Name
- Description
- Ingredients if available
- Price
- Availability

RTL:
Persian and Arabic are RTL.
English is LTR.

UX rules:
- No clutter.
- No unnecessary popups.
- No small modal for important pages.
- Mobile first.
